## 二、平台发布文案（可直接粘贴）

### 封面一句话
> **听幕 —— 给听障人士的面对面实时字幕 APP。对方一说话，大字立刻上屏。全程离线，音频不出手机。**

备选 slogan：
- 「听不见，也能看清每一句话。」
- 「把对话，写在屏幕上。」

### 一百字简介
> 听幕是一款面向听障人士的 Android 实时字幕 APP。打开后对着说话，屏幕上立即滚动出现大字字幕，正在说的内容半透明、说完自动定格；左上角蓝点随声音闪动，提示"有人在说"。识别引擎完全运行在手机本地（25MB 模型），**零网络请求、无账号、音频绝不出设备**，普通手机即可流畅运行。字号五档默认特大，白底黑字高对比，单手一碰屏幕即可调出停止/字号/配色。适合餐桌、医院、理发店、菜市场等面对面场景。

### 详细介绍
听幕只做一件事：让面对面的对话对听障用户"看得见"。

- **说话即上屏**：流式识别，正在说的字半透明实时更新，说话中间一停顿（约 0.6 秒）就在断口自动留一个空格，长停顿自动换行——不加任何标点，但一句话一眼能分块，换人说话时段落更清楚
- **全屏大字**：横竖屏自适应，字号 28–66sp 五档默认特大，白底黑字 / 黑底白字等高对比配色，夜间、户外强光下都醒目
- **极简交互**：待机页一个大按钮开始；运行时屏幕上只有字幕和左上角蓝点；手指一碰屏幕立即浮现五个小圆钮（停止、模型、缩小/放大字号、配色），8 秒自动收起，老年人/听障用户无需学习
- **完全本地，隐私优先**：模型在手机内，识别在手机 CPU，**不联网、不注册、不上传任何音频**——医院、家庭等敏感场景放心用；麦克风权限可随时在系统设置中收回
- **普通手机可跑**：25MB int8 模型，双架构包覆盖 32 位老机；也支持外挂更大模型（拷入手机目录即可在模型列表切换）

### 适用场景
家庭餐桌聊天 · 医院面诊问答 · 理发店/洗车店沟通 · 菜市场/便利店砍价 · 朋友聚会多人说话 · 工作场合快速沟通

### 性能口径（诚实版）
Mac 基准实时率 RTF 0.04，模拟器自测 RTF 0.09–0.17；真机实测数据（延迟、发热、续航）正在听障朋友外部测试中回填，回填后公布。

### 已知限制（不藏着）
- 目前以普通话为主，方言识别暂不准——已在规划"下载方言包"按钮，按实际反馈触发
- 同音字偶发错误（如"幕/目"），后续版本用同音纠正优化
- 不区分"谁在说"、不做会议总结——这是刻意不做的功能，保持简单可靠
- 多人**同时**说话时会相互干扰（实测：等响度只认出其中一人，响度接近则两句串在一起）；**轮流说话完全正常**——建议一次一人说话，手机放近说话人

### 隐私与安全
麦克风权限仅用于本机语音识别；APP 无网络权限请求，音频与文字全程留在手机；无账号体系，无云端上传。

### 下载与安装
当前未上架应用商店，提供 APK 直装包（需在系统设置允许"安装未知来源应用"）：
- 全量版 93MB（推荐，兼容 32 位老机）
- 轻量版 51MB（仅 64 位手机）
- 下载链接见发布页置顶评论 / 私信获取

首次使用请允许麦克风权限，然后点屏幕上的大按钮「开始识别」即可。

### 反馈渠道
欢迎听障朋友试用后反馈：机型与系统版本、出字延迟、准确率/错字、发热续航、哪些场景最常用、是否需要方言支持。每一条都会直接影响下一个版本。

## 三、平台选择建议

| 平台 | 形式 | 原因 |
|---|---|---|
| 少数派（sspai） | 文章 + 产品自荐 | 精准触达关心无障碍/效率工具的人群，可讲清"端侧离线隐私"故事 |
| 酷安 | 发布 APK + 置顶帖 | Android 直装社区，目标用户直接下得到包，评论区即反馈渠道 |
| 听障微信群 / QQ 群、残联渠道 | 直接发包 + 收反馈 | 真正的种子用户，反馈最准 |
| AppSo / 数字尾巴 | 产品收录 | 曝光向 |
| 应用商店（应用宝/小米/华为） | **暂缓** | 需签名备案与商店审核；当前 P0 未收尾，先用直装验证 |

发布节奏建议：先在 1–2 个听障社区拿到真实反馈 → 修一轮 → 再去少数派/酷安放大。

## 五、与调研结论的对应（防口径漂移）

- 方言：对外只说"普通话为主，方言包按需下载已在规划"，**不承诺具体方言/时间**（触发条件=外部反馈，见 notes/dialect-and-speaker-investigation-20261030.md §四）
- 说话人区分 / 总结：**明确说"目前不做"**，避免和得到类产品混淆预期
- 性能：只写已标注环境的实测数字；真机数字未回填前不说"手机上 XX 秒"
