# 听幕 Tingmu

给听障人士的**面对面实时字幕 APP**——对方一说话，手机屏幕上立刻出现大字字幕。
识别引擎完全跑在手机本地：**零网络请求、无账号、音频绝不出设备**。

> 一句话：别人用耳朵聊天，你用眼睛看——听幕把对话实时写在屏幕上。

## 下载（v1.9）

见 [Releases](../../releases)。三个版本**可在同一手机上同时安装**（包名不同，图标右下角有徽章字区分：双 / 快 / 方）。

**断句规则（三版一致，v1.7 起不显示任何标点）**：说话中间稍微停顿（约 0.6 秒）换 1.5 行；停顿超过 2 秒空一行（两段之间留一个空行）。

### 选哪个？先看这张表

| | **听幕双语版**（「双」） | **听幕快速版**（「快」） | **听幕方言版**（「方」） |
|---|---|---|---|
| **适用场景** | 通用主力 | 老手机/省电 | **方言对话** |
| **识别准确率** | **高**（真机实测明显高于快速版） | 一般 | 普通话略逊双语版；**方言明显更强** |
| **方言** | ❌ | ❌ | ✅ 常见方言（四川话等）支持好 |
| **英文/字母** | ✅ 能认（ABC、PDF、iPhone） | ❌ 不显示 | ✅ 能认 |
| **粤语** | ❌ | ❌ | ✅ 支持 |
| 标点/断句 | ❌ 无标点；0.6s 换 1.5 行、2s 空行 | ❌ 无标点；0.6s 换 1.5 行、2s 空行 | ❌ 无标点；0.6s 换 1.5 行、2s 空行 |
| **出字方式** | 逐字流式，几乎实时 | 逐字流式，最快 | **双通道**：先逐字实时出字，一句结束约 1 秒内用方言模型刷新成更准的整句（字幕会"跳一下"） |
| 语速快时 | 基本不丢词（真机实测） | 丢词明显 | 第一遍流式实时出，第二遍整句兜底 |
| 速度/耗电 | 较慢、较费电 | 快、省电、发热低 | 最高（双模型，但第二遍只在句末跑） |
| 文件大小 | ~165MB | ~76MB | ~209MB |
| 手机要求 | 仅 arm64（64 位） | arm64 + **32 位老机也能装** | 仅 arm64（64 位） |

**一句话建议**：
- **日常通用、要最好效果：双语版**——识别质量是字幕工具的生命线，真机上语速快也不丢词。
- **对方说方言：方言版**——三个版本里唯一能听方言的；先实时出字、句末自动刷新成更准的版本，代价是句末字幕会跳一下、包体较大。
- **老手机/内存小/只求省电：快速版**。

安装：允许"未知来源安装"后直接安装 APK；三个版本互不影响，各自独立数据。

## 使用

1. 安装后允许麦克风权限
2. 点屏幕上的大按钮「开始识别」
3. 对方说话，字幕滚动出字；说话中间停顿自动换 1.5 行，长停顿（2 秒以上）空一行（**方言版**：先实时出字，一句结束约 1 秒内自动刷新成更准的整句）
4. 运行中手指一碰屏幕即浮现小圆钮（■停止 / 模型 / A- / A+ / 配色），8 秒自动收起
5. 字号 5 档默认特大；配色默认白底黑字，可反转黑底白字

## 特性与边界

- 全屏大字滚动字幕（横竖屏自适应），正在说的半透明、说完定格
- 左上角蓝点随声音闪动 = 有人在说
- 端侧离线：模型在手机内，音频不出设备，医院/家庭等敏感场景放心用
- 已知限制：**方言请用方言版**（双语版/快速版只擅普通话）；方言版句末会把这一句字幕刷新成更准的版本（会"跳一下"，约 1 秒）；专有名词（人名/品牌名）可能听错
- 多人**同时**说话会串字，**轮流说话完全正常**，建议一次一人说话、手机放近说话人

## 真机实测表现（用户实机反馈，2026-11）

- **双语版**：日常对话准确率高；**语速快时基本不丢词**；**长时间使用无明显发热**（真机实测）
- **快速版**：出字速度更快，但准确率明显低于双语版；**语速快时丢词明显**
- **方言版**（v1.7）：模拟器端到端自测通过——双通道（流式第一遍 + SenseVoice 第二遍刷新）实时率约 0.23；**真机表现待实测反馈**
- 结论：把识别质量放第一位就装双语版；说方言用方言版；快速版的优势只在省电/老机型兼容

## 从源码构建

```bash
# 1. 下载官方模型（sherpa-onnx release，各自许可见上游）
./scripts/fetch-models.sh

# 2. 打包某个版本（自动下载模型、生成对应 logo 徽章，输出文件名自动带版本号）
scripts/build-apk.sh fast        # → 听幕-快速版-v<版本号>.apk
scripts/build-apk.sh bilingual   # → 听幕-双语版-v<版本号>.apk
scripts/build-apk.sh dialect     # → 听幕-方言版-v<版本号>.apk
```

需要：JDK 17、Android SDK（compileSdk 35）。sherpa-onnx AAR 已在 `android/Tingmu/app/libs/`。

## 目录结构

```
android/Tingmu/    App 源码（Kotlin，单 Activity；AsrEngine 负责模型发现/加载）
scripts/           build-apk.sh（三版本打包）/ gen_icon.py（logo 生成）/ fetch-models.sh（拉模型）
bench/             Mac 端流式 ASR 基准脚本（RTF/延迟/CER）
notes/             实测与缺陷记录（含方言、说话人分离、多人重叠语音调研）
docs/              产品梳理与平台发布文案、开发规划
```

## 技术栈

- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) AAR v2.0.1（Apache-2.0）端侧流式 ASR + Silero VAD
- 快速版模型：`streaming-zipformer-small-ctc-zh-int8-2025-04-01`（25MB)
- 双语版模型：`x-asr-480ms-...-zh-en-punct-int8-2026-06-05`（162MB，Xiaomi X-ASR）
- 方言版模型：`sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2025-09-09`（SenseVoice，233MB；方言/粤语/英/日/韩，离线整句识别 + VAD 切句）
- 方言版第一遍流式：`streaming-zipformer-small-ctc-zh-int8-2025-04-01`（25MB，与快速版同模型）
- 模型许可各见上游 release 页面，**不在本仓库内分发**
